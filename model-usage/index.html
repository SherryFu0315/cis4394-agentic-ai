      What this snapshot can tell us

      These are requests and tokens processed through OpenRouter, not model downloads or unique users. A larger token count can reflect more requests, longer inputs, longer outputs, or a combination.

      Counting models and calculating shares

      Every canonical model ID is kept separate; versions are not merged. The ranking sums the selected measure over observed rows and sorts from largest to smallest, breaking ties by model ID. It shows up to 100 observed models, 25 per page. Its denominator includes all disclosed models in the selected group. Country shares use the selected model’s reported total across all groups.

      Country groups, suppression, and missing observations

      Country refers to the request’s network location, not a person’s residence or nationality. “Suppressed country group” and “Unknown country” remain separate. Suppressed model IDs are excluded from model rankings. Published aggregates are retained without reconstructing hidden countries or models. A reported zero remains zero; an absent observation remains absent.

      Source and snapshot timing

      Source: OpenRouter’s licensed daily token volumes by request country.
