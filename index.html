Agentic AI: build systems that reason, act, and know when to stop.

Generative AI is evolving into agentic AI: systems that reason, plan, adapt, and collaborate in complex environments. This course teaches the foundations and the practice: from the agent loop and tool use to evaluation, safety, and deployment, ending in a real capstone agent.

🎓 Final class · Week 14 · posted Nov 19, 2026 · Wed Dec 2 (9:30 section) · Thu Dec 3 (4:30 section) · in person

Our last class is right after Thanksgiving: 90-second agent pitches, an agent playground, the Agent Radar vote and an optional make-up quiz

Week 14 is the first class after the break, in person in our usual room, and it is the one session where everyone’s agent is on the table. Bring your laptop with your agent running. Here is the plan for the day.

  • Before class, register your agent: add four things to the sign-up sheet: your name, your agent’s name, a one-sentence slogan that says what it does, and a working link to the agent. The link to the sheet is in the iCollege announcement for your section, not here. Make sure the agent opens for a classmate without any setup, and add a line of testing instructions if it needs one. This sheet is the list we open agents from during the pitches and the playground.
  • Agent Radar vote: we pick the most popular Agent Radar talk of the second half of the semester.
  • 90-second pitch: each student has 90 seconds to sell their agent to the class. A slide or two, a live demo, a video or just you talking: whatever works, as long as all of it fits inside the 90 seconds. The limit is a hard cut, so rehearse it and make every second count.
  • Agent playground: after the pitches, we spend the rest of the session trying each other’s agents from the sheet, with different tasks and odd inputs. Rating your peers is part of the final project, so plan to stay for the whole session. I will also run live prompt injection tests against some of the agents, to see how they hold up when the user does not play by the rules.
  • Optional make-up quiz at the end of class. If you take it, the score replaces your lowest quiz score.

Questions and the sheet link: the iCollege announcement for your section. If anything here differs from iCollege, iCollege wins.

How the course runs

Four modules, one capstone

Module 1

Foundations

LLMs → agents, the loop, agentic coding, prompting & context engineering, reasoning & planning.

Module 2

Tools & protocols

Tool use and function calling, MCP & A2A, memory & RAG.

Module 3

Eval, safety, governance

Evaluation & reliability, multi-agent systems, security & governance.

Module 4

Deployment & capstone

Deployment & agentic commerce, capstone studios, final presentations.

Build paths (all free): plain Python on a local Ollama model (code, the default from Week 5 on; LangGraph and the Gemini free tier optional) · LangSmith Fleet (no-code) · GitHub Copilot as the coding assistant · LangSmith for evaluation and observability. The capstone must be a real agent (the LLM owns control flow) with a named stop condition, one human gate, an eval harness, and a security review.
